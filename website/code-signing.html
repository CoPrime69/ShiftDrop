Code signing policy

How ShiftDrop's Windows releases are built and signed, who approves a signed release, and what the signed programs do on your PC.

About ShiftDrop

ShiftDrop is a free, open-source app for Windows 10 and 11 that converts and edits files without opening another program. Start dragging any file, press Shift, and a wheel of actions opens under the cursor: convert images, video, audio, documents, PDFs and archives, shrink files to a target size, strip metadata before sharing, or open a built-in editor. The result is saved next to the original, which is never changed. Download ShiftDrop or see all releases.

Signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

ShiftDrop is applying to the SignPath Foundation's program for open-source projects. Until signing is in place, releases are published unsigned, and Windows SmartScreen may ask you to confirm before the installer runs: choose More info, then Run anyway.

What is signed

  • The installer, ShiftDrop-Setup-<version>.exe, published on the GitHub releases page.
  • The programs built from this project's source and installed by it: ShiftDrop.exe, ShiftDrop-Updater.exe and ShiftDropWorker.exe.

The installer also carries ffmpeg.exe, an unmodified LGPL build of FFmpeg, fetched at a pinned version and checked against its SHA-256. It is third-party software and isn't signed under this policy.

How a release is built

  • Every release is built by GitHub Actions from the public source on the main branch. Nothing built on a personal computer is ever signed.
  • An approver listed below approves each signing request by hand, after the release's build and tests have passed.
  • Each release's SHA256SUMS.txt lists the installer's hash, so you can check the file you downloaded.

Privacy

ShiftDrop transfers no information about you, your files or your settings to other networked systems. Its only network use is a check for a new version: a separate program asks GitHub for the latest release, and you can turn it off during setup or in Settings › Updates. The full details are in the privacy policy.

Installing and removing

The installer puts ShiftDrop in your user profile, with no admin rights, and asks before it adds ShiftDrop to Windows startup and to the right-click menu. To remove it, open Settings › Apps › Installed apps, find ShiftDrop and choose Uninstall. That removes the program, its startup entry and its right-click entry. Your settings and history in %LOCALAPPDATA%\ShiftDrop stay; delete that folder to remove them too.

Reporting a problem

If you think a signed ShiftDrop file is harmful, or wasn't built from this project, report it privately as described in SECURITY.md.
