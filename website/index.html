Private by design

Every action runs on your PC, even with the network off. Nothing is uploaded, and there's no account and no tracking. The only thing that goes online is a daily check for a new version, which sends nothing about you or your files and can be turned off.

Questions, answered.

Does anything leave my PC?

No. Every action runs locally, even offline. The only network request is a daily check for a new version, sent by a separate updater with no cookies and no sign-in. Turn it off in Settings › Updates.

Do I need an account?

No. Install it and drag a file.

Is it really free?

Yes. It's free and open source, with no paid tier, no ads and no trial. The code is on GitHub.

Will it change my original files?

Never. Each result is a new file next to the original, such as photo (converted).webp. An existing file is never replaced, and History can undo any run.

Why does Windows warn me when I install it?

The installer isn't code-signed yet, so SmartScreen shows "Windows protected your PC". Choose More info, then Run anyway. You can check the download against the SHA256SUMS file on the release page.

What does it need?

Windows 10 22H2 or Windows 11, 64-bit. Video and audio tools are built in. Exact PDFs of Word, Excel and PowerPoint files need Microsoft Office or LibreOffice, and HEIC needs the free HEIF extensions from the Microsoft Store.

Is there a Mac or Linux version?

Not yet. ShiftDrop is a native Windows app for Windows 10 and 11.
