# What ShiftDrop's own ffmpeg.exe is built with (scripts/build-ffmpeg.sh), and what every bundled
# ffmpeg.exe must have (scripts/check-ffmpeg.ps1 asks the exe; tests/FfmpegComponentsTests.cpp checks
# that every codec, format and filter the argument builders name is listed here).
#
# Names are ffmpeg's own, as `ffmpeg -encoders` / `-decoders` / `-muxers` / `-demuxers` / `-filters`
# print them (build-ffmpeg.sh maps the few that configure spells differently, such as the 3gp muxer,
# configure's "tgp"). A name with * is a pattern over configure's --list-<section> (and is not checked
# one by one). Lines starting with # are comments. Any change here rebuilds ffmpeg.exe in CI.
